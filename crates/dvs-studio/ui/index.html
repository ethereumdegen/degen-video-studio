    step one frame

    Pane separators

    tab
    reach a separator; drag it with the pointer too
    ← → ↑ ↓
    move it 16 pixels
    page up page down
    move it 64 pixels

    end

    Inside the timeline

    ← →
    previous or next clip on this track
    ↑ ↓
    the track above or below
    home end
    first or last cell of this track
    ctrl+home end
    first or last track
    enter space
    select the clip under focus
    ctrl+scroll
    zoom around the pointer

    The timeline is a grid, so while focus is inside it home and end mean “this row” rather than “this sequence”.

    Playback runs forward only. The engine mixes audio forward, so a reverse transport would be a picture with no sound to keep it honest; step back a frame at a time with , or ← instead.
